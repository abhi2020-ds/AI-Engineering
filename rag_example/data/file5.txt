Indexing and Embedding Details

The embedding model used in this example is `nvidia/nv-embedqa-e5-v5`.
Key rules:
- Keep chunks smaller than 512 tokens.
- Use overlap so the query engine can recover context.
- Convert documents into nodes before building `VectorStoreIndex`.

Recommended settings:
- `chunk_size=150`
- `chunk_overlap=30`
- `similarity_top_k=7`
- `response_mode="compact"`

Use these settings to avoid token-limit errors and improve retrieval accuracy.
