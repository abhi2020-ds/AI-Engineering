Troubleshooting

Common project errors and fixes:
- `Input length ... exceeds maximum allowed token size 512`: reduce `chunk_size` to 150 or 120 and keep `chunk_overlap=30`.
- Missing packages: run `uv sync --active` inside `.venv`.
- Missing API key: ensure `.env` contains `NVIDIA_API_KEY=...`.
- Poor relevance: use more project-specific questions and verify the top retrieved nodes.

This dataset is designed to isolate only the project example content so the RAG notebook can be tested reliably.
