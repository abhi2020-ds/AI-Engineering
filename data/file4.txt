# Testing Best Practices for AI Applications

Testing AI applications requires special considerations due to the probabilistic nature of LLMs.

## Unit Testing

### Test Non-LLM Components

Standard unit tests work well for:
- Vector operations
- Document processing logic
- API endpoints
- Configuration management

```python
def test_vector_similarity():
    vector1 = [0.1, 0.2, 0.7]
    vector2 = [0.1, 0.2, 0.8]
    vector3 = [0.8, 0.8, 0.0]

    similarity_1_2 = cosine_similarity(vector1, vector2)
    similarity_1_3 = cosine_similarity(vector1, vector3)

    assert similarity_1_2 > similarity_1_3
```

## Integration Testing

### Mock LLM Responses

Use deterministic mocks for LLM calls in tests:

```python
from unittest.mock import patch, MagicMock
from llama_index.llms.nvidia import NVIDIA

@patch.object(NVIDIA, '_call')
def test_rag_pipeline(mock_call):
    mock_call.return_value = "Based on the documents, the answer is..."

    # Test the RAG pipeline
    response = query_engine.query("Test question")
    assert "Based on" in response
```

### Test Vector Store

```python
def test_vector_index_creation():
    documents = [
        TextNode("Document content here")
    ]
    index = VectorStoreIndex.from_documents(documents)

    # Query and verify
    response = index.as_query_engine().query("Document content")
    assert "Document" in response
```

## Evaluation Metrics

### 1. Answer Relevance

Measure how well retrieved documents answer the query:

```python
from llama_index.core.evaluation import RagEvaluator

evaluator = RagEvaluator(llm=llm)
scores = evaluator.evaluate_context_relevance(retrieved_contexts)
assert scores.mean() > 0.7
```

### 2. Answer Correctness

```python
from llama_index.core.evaluation import LlamaFactEvaluator

evaluator = LlamaFactEvaluator(llm=llm, gt_document=document)
scores = evaluator.evaluate(generated_answer)
assert scores["Faithfulness"].mean() > 0.85
assert scores["Answer Relevance"].mean() > 0.8
```

### 3. Context Precision

```python
from llama_index.core.evaluation import RagasEvaluator

# Evaluate multiple dimensions
evaluator = RagasEvaluator(
    query="How does dependency injection work?",
    retrieval_contexts=retrieved_contexts,
    llm=llm
)
```

## Testing Vector Search

### Test Retrieval Accuracy

```python
def test_retrieval_accuracy():
    index = VectorStoreIndex.from_documents(documents)
    query_engine = index.as_query_engine(similarity_top_k=3)

    query = "How do I implement RAG?"
    response = query_engine.query(query)

    # Check that retrieved contexts contain relevant information
    retrieved_docs = index.get_retriever().retrieve(query)
    assert any("retrieval" in doc.get_text().lower() for doc in retrieved_docs)
```

### Test Similarity Thresholds

```python
def test_retrieval_thresholds():
    retriever = Retriever.from_defaults(
        index=index,
        similarity_top_k=5,
        node_similarity=0.7  # Only retrieve documents with >70% similarity
    )

    results = retriever.retrieve(query)
    assert all(doc.get_score() > 0.7 for doc in results)
```

## Performance Testing

### Measure Latency

```python
import time

start = time.time()
response = query_engine.query(query)
latency = time.time() - start

assert latency < 5.0  # Should respond within 5 seconds
```

### Measure Token Usage

```python
from llama_index.core.llms import Token

tokens_used = 0
for token in response.metadata.get('tokens', []):
    tokens_used += token.get_length() or 0

assert tokens < max_tokens
```

### Clean Up After Tests

```python
@contextmanager
def temporary_documents():
    import shutil
    temp_dir = tempfile.mkdtemp()

    try:
        yield temp_dir
    finally:
        shutil.rmtree(temp_dir)
```

## Edge Cases to Test

1. Empty document collections
2. Very long documents
3. Documents with special characters
4. Queries with no matching documents
5. Queries with multiple topics
6. Rate limiting scenarios
7. API key expiration
