Example Questions and Expected Answers

Q: What are the main features of this project?
A: The project uses local document ingestion, NVIDIA embeddings, vector search with `VectorStoreIndex`, and a query engine for RAG answers.

Q: How do I implement a Retrieval Augmented Generation system with Python?
A: Load documents, split them into chunks, embed them, create a `VectorStoreIndex`, then query the index with a query engine.

Q: What dependencies are used for the RAG pipeline?
A: `langchain`, `langchain-nvidia-ai-endpoints`, `llama-index-core`, `llama-index-embeddings-nvidia`, `llama-index-llms-nvidia`, `llama-index-multi-modal-llms-nvidia`, and `python-dotenv`.

Q: How do I install and configure this project?
A: Activate `.venv`, run `uv sync --active`, add `NVIDIA_API_KEY` to `.env`, and open `rag_example.ipynb`.
