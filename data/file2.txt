Setup and Dependencies

This project is managed with `pyproject.toml` and `uv` for reproducible dependency installation.
Required packages include:
- `jupyterlab>=4.5.8`
- `langchain>=1.3.4`
- `langchain-nvidia-ai-endpoints>=1.4.1`
- `langchain-nvidia-langgraph` via GitHub
- `llama-index-core>=0.14.3,<0.15`
- `llama-index-embeddings-nvidia>=0.5.1,<0.6`
- `llama-index-llms-nvidia>=0.5.0,<0.6`
- `llama-index-multi-modal-llms-nvidia>=0.5.2,<0.6`
- `python-dotenv>=1.2.2`

Installation steps:
1. Activate `.venv`.
2. Run `uv sync --active`.
3. Add `NVIDIA_API_KEY=...` to `.env`.
4. Open `rag_example.ipynb` and run the notebook.
