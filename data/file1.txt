Project Overview

This example project demonstrates a Retrieval-Augmented Generation (RAG) pipeline for the AI Engineering repository.
It indexes local project documentation from the `data/` folder, creates embeddings with NVIDIA, and answers questions by retrieving the most relevant document chunks.

Main features:
- Local text ingestion with `SimpleDirectoryReader("data")`
- Chunking for model-safe embeddings
- Semantic retrieval with `VectorStoreIndex`
- Query answering through an NVIDIA-powered query engine
