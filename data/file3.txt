Document Processing and Queries

Documents are loaded with `SimpleDirectoryReader("data")` and must be chunked before embedding so the model never receives more than 512 tokens at once. The notebook uses `TokenTextSplitter` to split long documents into smaller chunks.

After chunking, the pipeline creates a `VectorStoreIndex` and then converts it into a query engine. Example queries include:
- "What are the main features of this project?"
- "How do I implement a Retrieval Augmented Generation system with Python?"
- "What dependencies are used for the RAG pipeline?"
- "How do I install and configure this project?"
