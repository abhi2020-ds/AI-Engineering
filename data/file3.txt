Pipeline and Architecture

The RAG workflow for this project follows these steps:
1. Read files with `SimpleDirectoryReader("data")`.
2. Split text using `TokenTextSplitter(chunk_size=150, chunk_overlap=30)`.
3. Create `VectorStoreIndex` from the chunked nodes.
4. Build a query engine with `similarity_top_k=7` and `response_mode="compact"`.

This architecture keeps each embedding input under the NVIDIA token limit and ensures the query engine focuses on project-specific content.
